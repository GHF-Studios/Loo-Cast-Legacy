The Loo Cast Game is the baseline first-party playable/content experience built on the [[Spacetime Engine]], with the
[[USF]] as the flagship first-party simulation framework.
It is intentionally designed so the player experience can flow toward creator agency through
the [[Player-to-Creator Path]].

Current disambiguation:
`Loo Cast` primarily names the first-party game.
Informally, it may also name the acquired flagship product bundle where the game grants access to the Spacetime Engine
and [[Vapor Ecosystem]] SDK/modding rails, similar to how a first-party Source game can imply access to Source SDK and
Steam ecosystem surfaces.
When precision matters, distinguish the game from the broader product stack.
