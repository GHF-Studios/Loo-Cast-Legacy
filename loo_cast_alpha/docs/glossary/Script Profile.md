A Script Profile is an older name for the [[Capability Slot Type]]/projection shape used by declaration-script
entrypoints.
Current active wording should generally use [[Capability Slot Type]] instead.
It defines what capability/API paths are script-safe for that declaration context and how those paths are projected as
Rhai-facing objects.
Whitelist policy is default; blacklist is an optional override policy.
